# ACMP Connect — краткая инструкция

Сервер MCP для ChatGPT: получение условий acmp.ru, сопоставление букв задач в темах, отправка кода и проверка настоящего вердикта. Решение генерирует ChatGPT, отдельный AI API не нужен.

Реальная проверка 16.10.2026: вход работает, cookies восстанавливаются, задачи №1 и №564 читаются, тема цикла for сопоставляется с ID задач. Создана одна тестовая отправка C++ №25641783 для задачи №1 — **Accepted**. Повтор с тем же ключом не создал новую отправку.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e '.[dev]'
python -m pytest -q
```

Скопируй `.env.example` в приватный `.env`. Настрой внешний OAuth/OIDC-провайдер, ключ шифрования и адрес сервера по [AUTH.md](AUTH.md). Сервер не запускается без обязательных настроек и не имеет режима отключения авторизации.

```powershell
python -m dotenv -f .env run -- acmp-server
```

Для HTTP на своём компьютере: `PUBLIC_URL=http://localhost:8000`, `ACMP_DEV=1`. Для хостинга — HTTPS и `ACMP_DEV=0`. В Docker используй обычный серверный режим.

## Подключение

1. Подготовь HTTPS-развёртывание по [RAILWAY.md](RAILWAY.md).
2. Создай OAuth-клиент ChatGPT и отдельный OIDC-клиент страницы подключения. У пользователя должен совпадать `sub` в обоих клиентах.
3. В веб-версии ChatGPT добавь собственный MCP по URL `https://ТВОЙ_ДОМЕН/mcp`, выбери OAuth и пройди вход. Подробности в [CHATGPT.md](CHATGPT.md).
4. Попроси проверить аккаунт, открой защищённую страницу `/connect` и введи там логин/пароль ACMP. В чат пароль не отправляй.
5. Попроси прочитать задачу, написать код и, когда нужно, явно отправить решение. После отправки проверяй настоящий вердикт.

## Ограничения

- На момент проверки у ACMP нет отдельного компилятора C. Сервер поддерживает выбор настоящего C, если он появится в форме; сейчас явно отказывает, не подменяя его C++.
- CAPTCHA и ограничения сайта не обходятся. При неоднозначном результате отправки нельзя автоматически отправлять заново; сначала проверь историю и сопоставь ID через `reconcile_submission`.
- Проверка старых отправок ограничена пятью страницами личного статуса. Поиск темы по имени — первый курс; для других курсов передай точную ссылку.
- Cookies зашифрованы, пароль не сохраняется. Отключение и удаление данных доступны на странице и через MCP. Подробнее в [PRIVACY.md](PRIVACY.md).
- Локальный MCP и Docker проверены. Настоящий внешний OAuth tenant, подключение ChatGPT и Railway-деплой ещё не выполнены. Настройка Desktop/mobile отдельно не подтверждена.
- В официальный каталог текущий неофициальный коннектор не может считаться допущенным: правила OpenAI запрещают одобрение таких коннекторов. Нужны разрешение ACMP и уточнение допуска у OpenAI. См. [PUBLICATION.md](PUBLICATION.md).

Аккаунт Railway доступен, но платные ресурсы и публичное развёртывание не создавались. Секреты тестового аккаунта в проект не записаны.
